# Recursos de Marketing Reset

Skills de Claude y otros recursos para profesionales de marketing, publicados en [Marketing Reset](https://www.marketingreset.es).

Cada carpeta es un recurso. Cada uno tiene su artículo en marketingreset.es, que explica qué hace, cómo se probó y sus limitaciones.

## Cómo instalar una skill

**Descarga el .zip** de la skill desde su artículo o desde [Releases](https://github.com/Josellinares/marketingreset-recursos/releases).

**En Claude (claude.ai o la app de escritorio):**
1. Ve a *Configuración → Capacidades → Skills*.
2. Pulsa *Subir skill* y elige el .zip.
3. Actívala y pídele a Claude la tarea en lenguaje normal.

**En Claude Code:**
1. Descomprime el .zip.
2. Copia la carpeta a `~/.claude/skills/` (para todos tus proyectos) o a `.claude/skills/` dentro de un proyecto.

Cada carpeta incluye un `LEEME.md` con lo que necesitas (herramientas, conexiones, permisos) y cómo usarla.

## Antes de usarla

- Revisa el `SKILL.md`: es texto, puedes leer exactamente lo que le pide a Claude.
- Pruébala primero con datos que no sean sensibles.
- Si encuentras un fallo, abre un *issue* en este repositorio.

---

Todos los recursos están probados por Marketing Reset antes de publicarse. Marketing Reset es un medio independiente: no promociona agencias ni clientes.
